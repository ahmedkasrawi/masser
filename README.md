# منصة مسار للاستشارات (Masser Platform)

منصة رقمية متكاملة لربط العملاء بنخبة من الخبراء والمستشارين المعتمدين مع نظام حجز وتقويم ذكي للأيام السبعة القادمة ونموذج مالي عادل (80% للخبير / 20% للمنصة).

---

## هيكل المستودع المنظم (Repository Structure)

```
masser/
├── client/              # تطبيق الواجهة الأمامية (Next.js + React 19 + TypeScript + Tailwind)
│   ├── public/          # الأصول والملفات الثابتة
│   └── src/             # مجلدات الواجهة المنظمة (app, components, hooks, services, types...)
│
├── docs/                # التوثيق الفني والمواصفات المعتمدة والنموذج الأولي
│   ├── PRD.md                  # وثيقة متطلبات المنتج الرسمية
│   ├── userstory.md            # قصص المستخدم ومعايير القبول Agile
│   ├── schema.sql              # مخطط قاعدة بيانات PostgreSQL
│   ├── ARCHITECTURE.md         # الهيكل المعماري وخريطة مسارات الـ API
│   ├── DESIGN_SYSTEM.md        # المواصفات الهندسية لنظام التصميم والألوان
│   └── prototype.html          # النموذج الأولي التفاعلي المتكامل v3.0
│
├── MEMORY.md            # ذاكرة وسياق المشروع وسجل القرارات (Single Source of Truth)
└── README.md            # دليل تصفح المستودع العام
```
